# Java 25 代码现代化

## 背景与方案

短链有效期内部改用 `ZonedDateTime`，在类型可以从初始化表达式直接判断的局部变量上使用 `var`。继续使用 JVM 默认时区计算自然日，并在 API、数据库映射和缓存边界沿用现有时间格式。Redis Stream 幂等标记改用接受 `Duration` 的 API。

通过 `SPRING_THREADS_VIRTUAL_ENABLED=true` 可开启 Spring Boot 虚拟线程。开启时同步启用 JVM keep-alive。应用自建的 Redis Stream 消费线程池仍使用原有配置。

## 验证

- Java 25 下执行 `mvn clean package -Dmaven.compiler.showDeprecation=true`，45 项后端测试通过。
- 启用虚拟线程后，使用 MySQL 8 和 Redis 8.12.0 验证容器内 Tomcat 请求处理、短链创建、跳转和 Stream 统计。
- 通过 HTTP 验证默认一天、最多三天和拒绝已过期时间的有效期规则。

## 后续

其他 Redis TTL 调用仍有弃用重载，时间模型也可以按模块继续迁移。虚拟线程尚未做性能对比。
