# 升级 Redis 8.12.0

## 背景

Docker Compose 此前使用 Redis 7.0。更新到 2026-11-22 发布的 Redis 8.12.0 稳定版。

## 方案与影响

将 Compose 服务固定到官方 `redis:8.12.0-alpine` 镜像。沿用 AOF、认证、数据卷和应用侧的 Redis 命令。已有部署按 README 先备份整个数据卷，并在副本上验证。回退使用升级前的备份。

## 验证

- `docker compose config --images` 解析出固定版本镜像。
- 在隔离容器里用 Redis 7.0 创建短链并记录访问，然后遗留一条超时待确认的统计消息。停止应用和 Redis 后，使用相同的 AOF 数据卷启动 Redis 8.12.0。
- 用原登录会话查询分组，验证旧短链仍能跳转、号段计数从 10000 延续到 20000、新短链仍能创建和跳转。
- 应用通过 `XAUTOCLAIM` 恢复并统计了遗留消息，待确认队列归零。新访问事件正常消费，Lua 用户限流在第六次写请求时返回 HTTP 429。

## 遗留验证

本次使用隔离测试数据，未对已有部署执行升级或复测性能。
